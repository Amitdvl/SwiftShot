## Important boundaries

- Historical one-frame refusals prove incomplete warnings, **not successful automatic scrolling**. Diagnostic-free production now has bounded Auto/Stop/loss witnesses, but exact full-page pixels, full accepted-frame provenance and the earlier unexplained dynamic refusals remain open. Earlier activity/flush/extra-query experiments were removed. The original reference all-overlap oracle remains unsatisfied: adjacent reference RGB values differ by up to2, with no established upstream cause. Do not reinterpret a contributing-partition check as that original oracle passing. No identity checks or other apps were weakened/altered.
- Native manual/sticky scrolling verifies a clean 300×480-point source strip at 2× with observed positions 0/200/400. It is not arbitrary full-width/browser/Auto acceptance or a claim to detect the page bottom.
- Render/cache/OCR coordination tests exercise actual code and isolated files; they do not establish OS permission, display, or crash behavior. Idle CPU zero delta over one old 60-second interval is not repeated-session memory or current-build idle acceptance.
- The encoder's marked-source/container and actual private Copy/Save regression tests now verify tested opaque masks, native/smaller geometry, one-image PNG/CRC/exact-EOF structure and absence of supplied source metadata/embedded-original witnesses. They permit legitimate output color/dimension metadata. This is bounded synthetic evidence plus an older native-file audit; current final-build native/smaller capture exports remain required.
- Only one built-in display is available. Native multidisplay, other refresh rates, HDR and macOS 14/Intel runtime are unavailable/unverified, not passing. macOS Screenshot is present; CleanShot X and Shottr were not found in fresh application checks.
- Pre-existing icon/design/signing/install and overlapping capture/export edits belong to the user. No blanket staging, reset, force quit, force push or unrelated publication is authorized by this audit.
